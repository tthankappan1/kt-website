# Listings Section Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `/listings` and `/listings/553-covington-way-livermore` on kalyanithilak.com so the home's launch traffic lands on our domain, with a content model that carries future listings through active → pending → sold.

**Architecture:** Typed TS content files in `src/content/listings/` (publish = add file + push, like posts), two SSG routes, a `src/components/listing/` family composed by `ListingPageView`, photos self-hosted under `public/images/listings/<slug>/`, and the inquiry form reusing the existing `/api/lead` route unchanged.

**Tech Stack:** Next.js 15 App Router, React 19, TS 5, Vitest + RTL, `next/image`, existing `.kt-*` design system in `src/app/globals.css`.

**Spec:** `docs/superpowers/specs/2026-09-03-listings-design.md`

## Global Constraints

- Brand: gold `#C0A278` on dark only, gold-deep `#7E6A4F` on light only; Fraunces + Inter via `next/font` only; hairline borders with top-left-only radius (buttons 12px, cards 24px); dark bookends on every page; no emoji; INTERO re-typed in Fraunces gold caps; compliance line `Kalyani Thilak · DRE 02254890 · Intero Real Estate Services`.
- Layout: `.kt-container` 1200px / 48px gutters (24px ≤900px); `--sect-pad` 96px (72px ≤700px); `--dm: 1`.
- Static-first: both routes SSG; `dynamicParams = false`; `src/lib/images.ts` build-time constraint applies (never make these routes dynamic).
- CSP `img-src 'self'`: photos must be self-hosted; no map iframes.
- No `dangerouslySetInnerHTML` (documented CSP invariant in `next.config.ts`).
- Content strings with apostrophes use template literals (CLAUDE.md ingestion rule).
- Consent invariant: the inquiry form never subscribes anyone (`newsletterAlameda: false`, `newsletterContracosta: false`).
- Gates before "done": `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm build`; then `pnpm verify:routes` and `node scripts/mobile-verify.mjs` against the build.
- Facts (owner-supplied): $890,000 · 3 bd · 2 ba · 1,130 sq ft · built 1969 · 6,000 sq ft lot · Summerset, Livermore · single-family · no HOA · as-is · status active, listed 2026-09-03.

```ts
export type ListingStatus = 'coming-soon' | 'active' | 'pending' | 'sold'
export type PhotoGroup = 'exterior' | 'living' | 'kitchen' | 'bedrooms' | 'baths' | 'outdoor'
export type ListingPhoto = { file: string; alt: string; group: PhotoGroup }
export type OpenHouse = { date: string; start: string; end: string }
export type Listing = {
  slug: string; status: ListingStatus
  street: string; city: string; state: 'CA'; zip: string; neighborhood?: string
  price: number; soldPrice?: number
  beds: number; baths: number; sqft: number; lotSqft?: number; yearBuilt?: number
  garage?: string; propertyType: string; listedDate: string; mls?: string
  headline: string; description: string[]; highlights: string[]; facts: [string, string][]
  openHouses?: OpenHouse[]
  hero: string; photos: ListingPhoto[]; floorPlans?: { file: string; alt: string }[]
  mapsQuery?: string
}
// index.ts
export const LISTINGS: Listing[]
export const STATUS_LABEL: Record<ListingStatus, string> // active 'For sale', coming-soon 'Coming soon', pending 'Pending', sold 'Sold'
export const GROUP_LABEL: Record<PhotoGroup, string>     // exterior 'The exterior', living 'Living room', kitchen 'Kitchen & dining', bedrooms 'Bedrooms', baths 'Baths', outdoor 'Outdoor'
export function getListing(slug: string): Listing | undefined
export function getListings(): Listing[]                 // status rank (active, coming-soon, pending, sold) then listedDate desc
export function listingPath(slug: string): string        // `/listings/${slug}`
export function listingAddress(l: Listing): string       // '553 Covington Way, Livermore, CA 94551'
export function photoSrc(l: Listing, file: string): string // `/images/listings/${slug}/${file}`
export function formatPrice(n: number): string           // '$890,000'
export function statLine(l: Listing): string             // '3 bd · 2 ba · 1,130 sq ft · 6,000 sq ft lot'
export function heroLabel(l: Listing, today?: Date): string // active + ≤21 days since listedDate → 'Just listed'; else STATUS_LABEL
export function mapsUrl(l: Listing): string              // google maps search URL for mapsQuery ?? listingAddress
```
